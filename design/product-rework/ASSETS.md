# Local illustration assets

Generated using the built-in image-generation tool, using the user's approved
stylized adult athlete as reference. These are synthetic illustrations, not
patient photographs. Final files are vendored under `public/illustrations/`.

- wheelchair-press.png: approved `design/explorations/01-stylized-3d.png`.
- chair-press.png: reference edit replacing the wheelchair with a sturdy ordinary
  armless chair while preserving the athlete, outfit and raised-arm posture.
- standing.png: reference edit showing the same athlete standing with arms relaxed.
- chair-curl.png: reference edit showing the same athlete in true side view,
  seated on an ordinary chair, demonstrating a curl with a small dark dumbbell.
- wheelchair-curl.png: corresponding side-view wheelchair curl reference.

The descriptions above summarize the edit prompts, rather than claiming to be
verbatim transcripts. Original exploration prompts are in `../explorations/prompts.json`.
No downloaded stock imagery, CDN assets, Blender model, or independently timed
animation is used. The images are labeled as references in the interface.
